# 安吉星 (OnStar China) for Home Assistant

把**上汽通用（别克 / 凯迪拉克 / 雪佛兰）**车辆通过**安吉星**接入 Home Assistant。

支持：

| 实体 | 类型 | 说明 |
|---|---|---|
| 车门锁 | `lock` | 上锁 / 解锁 |
| 远程启动 | `button` | 远程启动发动机 |
| 取消启动 | `button` | 取消远程启动 |
| 闪灯鸣笛 | `button` | 寻车 |
| 取消闪灯鸣笛 | `button` | 停止鸣笛闪灯 |
| 油量 (%) | `sensor` | 剩余油量百分比 |
| 油量 (L) / 油箱容量 | `sensor` | 剩余油量 / 油箱容量 |
| 剩余续航 | `sensor` | 还能跑多少公里 |
| 总里程 | `sensor` | 车辆总里程（odometer） |
| 机油寿命 | `sensor` | 机油剩余寿命 % |
| 胎压 左前/右前/左后/右后 | `sensor` | 四轮胎压 (kPa) |
| 上次行程里程 / 油耗 | `sensor` | 上一段行程数据 |
| 综合油耗 | `sensor` | 全生命周期平均油耗 |
| 胎压告警 | `binary_sensor` | 任一胎压异常时 on |
| 最后指令结果 | `sensor` | 上一条远程指令的成功/失败 |

> ℹ️ 车况来自车辆**上次上报**的数据（不是实时值）。每个传感器的属性里有「数据时间」。

> ⚠️ **非官方接口**。逆向自安吉星微信小程序，随时可能失效，且存在账号风控风险。
> 请使用**低频**操作，切勿高频轮询。**车控指令是真实操作车辆**，请自行评估风险。

## 安装

### 方式一：HACS（推荐）

1. HACS → 集成 → 右上角 ⋮ → **自定义仓库 (Custom repositories)**
2. 仓库地址填入本仓库 URL，类别选 **Integration**
3. 搜索「安吉星 / OnStar China」安装
4. **重启 Home Assistant**

### 方式二：手动

把 `custom_components/onstar_cn/` 整个文件夹复制到你的 HA 配置目录下的
`custom_components/`（通常 `/config/custom_components/`），然后重启 HA。

---

## 配置

HA → **设置 → 设备与服务 → 添加集成** → 搜「**安吉星**」→ 填入三项：

| 字段 | 说明 |
|---|---|
| 用户 ID (idpUserId) | 形如 `LADPA017243106` |
| perm_token | 一长串（256 字符左右） |
| 车架号 VIN | 17 位，如 `LSGZR5359PH094753` |

### 这三项怎么拿？（重要）

因为安吉星的登录**绑定在微信**上（密码登录也必须带微信产生的 code），
所以无法直接在 HA 里用账号密码登录 —— 需要你**从安吉星微信小程序抓一次登录请求**，
把凭据取出来。**只需做一次**，之后集成会自动刷新令牌。

完整图文步骤见 **[docs/获取凭据.md](docs/获取凭据.md)**，简要版：

1. 手机/电脑上用抓包工具（Reqable、Charles、Stream 等）抓**微信小程序「安吉星」**的流量
2. 在小程序里登录一次，找到这条请求：`POST /sos/miniapp/v1/oauth/token`
3. 在它的**响应**里找：
   - `perm_token` → 引号里那串长字符串
   - `username` → 同一段里的用户 ID（形如 `LADPA...`）
4. VIN 随便搜 `vin`，17 位那个就是

---

## 令牌失效怎么办

`perm_token` 会因为**账号在别处重新登录**（例如打开手机 App、换设备登录）等原因失效。
届时 HA 会提示该集成需要重新认证：

- 点 **「重新配置」**，把新取到的 `perm_token` 粘进去即可；
- 不用删除集成，实体和自动化都保留。

## 常见问题

**Q：为什么不能直接填手机号 + 密码？**
A：安吉星把登录绑在微信上，密码登录接口也强制要求携带微信 `wx.login` 产生的 code
（服务端要用它换 openid）。微信之外拿不到，实测返回 `E3011 Get openid failed`。

**Q：会封号吗？**
A：属于非官方接口，理论上存在风控可能。集成默认 30 分钟才刷新一次车况，指令只在
你手动点击时下发，属于低频使用。**用不用、怎么用，风险自负。**

**Q：我的车支持吗？**
A：只要在安吉星微信小程序里能远程控制的车（上汽通用旗下）基本都支持。
本集成只做「锁车 / 解锁 / 远程启动 / 寻车 / 油量」，其它功能暂未实现。

**Q：数据准吗？**
A：所有车况（油量/里程/胎压/机油寿命）都来自安吉星 `lastDiagnostics` 接口，
是车辆**上次上报**的快照，可能不是实时值 —— 每个实体的属性里能看到「数据时间」。
