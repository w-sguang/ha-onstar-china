# 如何获取凭据

集成需要 **4 项**：

| 凭据 | 必填 | 从哪来 |
|---|---|---|
| 用户 ID (idpUserId) | ✅ | 抓包：登录响应里的 `username` |
| perm_token | ✅ | 抓包：登录响应里的 `perm_token` |
| 车架号 VIN | ✅ | 抓包里的 `vin`，或行驶证 |
| 服务密码（PIN） | ⭕ 选填 | **你自己知道**，安吉星 App 里车控时输的那个 |

前三项来自**同一次抓包**；服务密码不用抓，你自己填。

> 为什么不能像别的集成那样直接填手机号密码？因为安吉星把登录**绑死在微信**上，
> 密码登录也必须带一个只微信能生成的 code，所以必须在微信环境里登录一次。

---

## 一、准备抓包

任选一种：

- **电脑**：装 [Reqable](https://reqable.com/) 或 Charles，配置好 HTTPS 证书。
- **手机**：用 Stream / Thor / HTTP Catcher 之类的抓包 App 也行。

关键是要能抓到**微信小程序**里的 HTTPS 请求（需要装上根证书信任）。

## 二、登录一次

1. 打开**微信 → 安吉星小程序**
2. **退出登录**（如果已登录），再**重新登录**一次（会过一道滑块验证）
3. 抓包工具里应该能看到一串发往 `api.shanghaionstar.com` 的请求

## 三、找前三项

### 1) 找到登录请求

**最省事：直接在抓包结果里搜 `perm_token`**，一下就命中。

也可以按接口名找，登录接口有两个（取决于你用哪种方式登录）：

| 登录方式 | 接口 |
|---|---|
| 微信登录（小程序默认） | `POST /sos/miniapp/v1/oauth/wechatRegisterAndLogIn` |
| 手机号+密码登录 | `POST /sos/miniapp/v1/oauth/token` |

搜 **`oauth/wechatRegisterAndLogIn`**（微信登录）或 **`oauth/token`** 都能找到。

看它的 **响应体（Response）**，成功时是一段 JSON，长这样：

```json
{
  "bizCode": "E0000",
  "bizMsg": "Success",
  "bizData": {
    "access_token": "……",
    "expires_in": 1800000,
    "perm_token": "7UUmW20681…（很长一串）",
    "username": "LADPA017243106"
  }
}
```

- ✅ **perm_token** = `perm_token` 后面引号里的那串（256 个字符左右）
- ✅ **用户 ID** = 同一个 `bizData` 里的 `username`（形如 `LADPA` 开头 + 数字）

> 💡 认准**同一个 `bizData` 里同时有** `access_token`、`perm_token`、`username` 的那段，
> 那就是登录成功的那条。别拿成 `oauth/refresh` 之类的其它响应。

### 2) 找 VIN 车架号

随便搜 **`vin`**，会看到两种形式，都是同一个 17 位值：

- URL 里：`…?vin=LSGZR5359PH094753`
- 请求体里：`"vin": "LSGZR5359PH094753"`

✅ **VIN** = 那个 17 位的大写字母 + 数字（车身铭牌 / 行驶证上也有）

---

## 四、服务密码（PIN）

**不用抓包**，就是你在**安吉星 App 里做远程控制时输入的那个密码**（通常 6 位数字）。

- 只用车况传感器 → **不用填**
- 要用锁车 / 解锁 / 远程启动 → **必须填**

> 忘了密码？只能在**安吉星 App** 里重置（一般叫「服务密码」/「远程控制密码」）。

---

## 五、填进 HA

**设置 → 设备与服务 → 添加集成 → 安吉星** → 把 4 项填进去 → 完成 🎉

## 六、如果导出的是 HAR 文件

用文本编辑器打开 HAR（就是个 JSON），按 `Ctrl/Cmd + F` 搜：

1. `perm_token` → 复制引号里的值
2. `username` → 复制值
3. `vin` → 复制 17 位值

> ⚠️ HAR 里引号是**转义**的，长这样：`\"perm_token\":\"7UUm…\"`
> 只复制引号**里面**的内容，别把 `\` 和引号一起复制进去。

---

## 七、以后失效了怎么办

安吉星是**单点在线**的：只要你在小程序里**重新登录**，旧 `perm_token` 立即作废。

失效时 HA 会提示「需要重新认证」→ 点 **「重新配置」** → 把**重新抓到**的 `perm_token`
粘进去即可，实体和自动化都保留。

> 💡 想少掉线：抓完就别再去小程序重新登录了。**App 里正常使用不影响**（刷新不会轮换
> `perm_token`）。
