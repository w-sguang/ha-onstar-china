# 如何获取那三项凭据

集成需要三样东西：**用户 ID (idpUserId)**、**perm_token**、**VIN 车架号**。
它们都来自同一次抓包，只要跑一遍登录就有了。

> 为什么不能像别的集成那样直接填手机号密码？因为安吉星把登录**绑死在微信**上，
> 密码登录也必须带一个只微信能生成的 code，所以必须在微信环境里登录一次。

---

## 一、准备抓包

任选一种：

- **电脑**：装 [Reqable](https://reqable.com/) 或 Charles，配置好 HTTPS 证书。
- **手机**：用 Stream / Thor / HTTP Catcher 之类的抓包 App 也行。

关键是要能抓到**微信小程序**里的 HTTPS 请求（需要装上根证书信任）。

## 二、登录一次

1. 打开**微信 → 安吉星小程序**
2. **退出登录**（如果已登录），再**重新登录**一次（会过一道滑块验证）
3. 抓包工具里应该能看到一串发往 `api.shanghaionstar.com` 的请求

## 三、找三项数据

### 1) 找到登录请求

在抓包结果里搜关键字 **`oauth/token`**，锁定这一条：

```
POST /sos/miniapp/v1/oauth/token
```

看它的 **响应体（Response）**，成功时是一段 JSON，长这样：

```json
{
  "bizCode": "E0000",
  "bizMsg": "Success",
  "bizData": {
    "access_token": "……",
    "expires_in": 1800000,
    "perm_token": "7UUmW20681…（很长一串）",
    "username": "LADPA017243106"
  }
}
```

- ✅ **perm_token** = `perm_token` 后面引号里的那串（256 个字符左右）
- ✅ **用户 ID** = 同一个 `bizData` 里的 `username`（形如 `LADPA` 开头 + 数字）

> 💡 认准**同一个 `bizData` 里同时有** `access_token`、`perm_token`、`username` 的那段，
> 那就是登录成功的那条。别拿成 `oauth/refresh` 之类的其它响应。

### 2) 找 VIN 车架号

随便搜 **`vin`**，会看到两种形式，都是同一个 17 位值：

- URL 里：`…?vin=LSGZR5359PH094753`
- 请求体里：`"vin": "LSGZR5359PH094753"`

✅ **VIN** = 那个 17 位的大写字母 + 数字（车身铭牌 / 行驶证上也有）

---

## 四、填进 HA

**设置 → 设备与服务 → 添加集成 → 安吉星** → 把三项粘进去 → 完成 🎉

## 五、如果导出的是 HAR 文件

用文本编辑器打开 HAR（就是个 JSON），按 `Ctrl/Cmd + F` 搜：

1. `perm_token` → 复制引号里的值
2. `username` → 复制值
3. `vin` → 复制 17 位值

> ⚠️ HAR 里引号是**转义**的，长这样：`\"perm_token\":\"7UUm…\"`
> 只复制引号**里面**的内容，别把 `\` 和引号一起复制进去。
